Protocol contract: Socket.IO at path `/arena/socket.io`. Connect with `auth: { token?: string }`; server sends `arena:session` ({token,snapshot}), then `arena:state` snapshots. Send validated `ArenaCommand` on `arena:command` with an optional ack callback returning ArenaAck. `arena:ping` callback returns `{serverNow:number}` for approximate countdown clock offset only. Server alone changes scores. Client never sends player IDs, scores or authoritative timestamps. Match/history shape is defined in protocol.ts. Token belongs in sessionStorage (independent guest identities per browser/tab), never a room URL. Profiles are editable only outside a room/queue. A server restart rejects old tokens with Socket.IO connect_error data `{code:'SESSION_EXPIRED'}`; reconnect once as a fresh guest and disclose lost in-memory state.

Rendering contract: ArenaStage props `{match: ArenaMatch, selfId:string, reducedMotion:boolean}`. Slot order always determines left/right (both clients see same sides). Each player's monster is `{appearance:{kind:'starter',id:'warden'|'wisp'|'oracle',name} | {kind:'drawing',dataUrl,name},hash}`. Purely cosmetic `match.event` drives backlash, attacks and finishing performance. Scores and history never change in a graphics callback. Use BattleViewport (1920×1080 logical fit).
